# Suporte

## Como pedir ajuda

Use uma issue para bugs reproduzíveis, dúvidas técnicas públicas e sugestões de melhoria. Descreva o fluxo afetado, comportamento observado, resultado esperado e, quando possível, passos para reproduzir usando dados fictícios.

Antes de abrir a issue:

- consulte o [README](README.md) e o [guia técnico](docs/REPOSITORY_GUIDE.md);
- confirme que dados de clientes, e-mails, CNPJ, telefones e números de orçamento foram removidos do relato;
- não inclua variáveis de ambiente, tokens ou credenciais.

Para segurança, siga [SECURITY.md](SECURITY.md). Para ativos de marca, use [CKF Design](https://github.com/Kauerc10/ckf-design).
